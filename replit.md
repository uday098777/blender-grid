# Pirate's Quest

## Project overview

This is a full-screen React + Vite + Three.js experience using the uploaded original GLB files in `attached_assets/`.

- The book is the opening scene; click it to reveal the map.
- The map scene places the Black Pearl at the bottom and Jack Sparrow's compass at the top.
- The original GLB geometry and materials are loaded directly; no placeholder models or external services are required.

## Run locally or in Replit

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 5000
```

The configured Replit workflow runs the same command on port 5000.
